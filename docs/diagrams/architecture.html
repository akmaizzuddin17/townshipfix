Intake: from report to ranked ticket (in order)

1Privacy guard

Strips photo metadata; blurs faces and number plates before anything is saved

2Locate

GPS inside the photo, else phone GPS, else the area the resident picked

3Understand

Malay + English keywords → problem type; danger words (live wire, bau gas…) → emergency

4Duplicate check

Open tickets within 80 m: distance + type + same-scene photo match (SIFT + RANSAC) → merge, suggest or new

5Impact priority

Severity + who is affected (wheelchair, school, elderly, night) + reporters + waiting time = score /100 with reasons

6Route + notify

Problem type → team and fix-by time; P0 emergency → security, 2 h target

Repair: from job to verified fix (in order)

AAssign + start

Crew named; every resident on the ticket is told

BAfter photo

Taken on site by the crew from where residents stood

CVerify evidence

Same place? visible change? not a reused photo? taken after the report? within 50 m? Any fail → stays open

DResident check

Sees before and after side by side; confirms, or reopens with a reason

EClose

Confirmed, or auto-closed 72 h after a verified fix; override needs a written reason

Claude vision API

Optional second opinion on the photo in step 3. Off unless an API key is set; falls back to keywords on any error.

SMS / WhatsApp gateway

Next step. Today messages go to an outbox shown on the dashboard.
